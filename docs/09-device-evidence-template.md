# Device Evidence Template

Use this file as the copy source for each physical test pass. The preferred path is to run `scripts/android-device-smoke-test.sh --write-evidence`, which creates a starter report under `data/runs/<date>_android_phone_smoke/device-evidence.md` and runs `scripts/validate-device-evidence.mjs` when Node.js is available. Fill in the remaining manual checks after the script finishes.

Manual validation command:

```bash
scripts/validate-device-evidence.mjs data/runs/<date>_android_phone_smoke/device-evidence.md
```
